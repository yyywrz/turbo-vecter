# Turbo‑Vecter

Turbo‑Vecter 是一款科幻风光标增强扩展，让每个页面都拥有高能量视觉反馈。选择模式后，移动与悬停都会触发独特效果，但不会打扰浏览体验。

## 亮点
- **即时反馈**：移动与悬停都有清晰的视觉响应。
- **电影质感**：平滑拖尾、霓虹光感与闪电电弧。
- **自适应配色**：深色与浅色模式切换，在任何网站都有最佳可见度。
- **开箱即用**：安装后无需设置即可在任意页面生效。

## 模式
- **关闭** — 一键停用所有效果。
- **磁** — 光标移动时留下收缩圆圈轨迹。悬停元素时边框循环动画：实线 → 虚线 → 流动 → 抖动。
- **光** — 光剑式拖尾，悬停元素时显示发光蛇形环绕动画。
- **电** — 移动时电弧分段跳跃，悬停时闪电充能元素并产生明亮静态光效。

## 行为说明
- **移动时**：光标移动时每种模式都有专属动效表现。
- **悬停时**：元素产生对应动画反馈（流动边框/蛇形环绕/闪电充能）。
- **静止时**：效果自动减弱，保持轻量。

## 隐私
Turbo‑Vecter 仅保存所选效果与语言到扩展存储，不收集或上传任何数据。见 [PRIVACY.md](PRIVACY.md)。
