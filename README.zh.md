# Turbo‑Vecter

Turbo‑Vecter 是一款科幻风光标增强扩展，让每个页面都拥有高能量视觉反馈。选择模式后，移动与悬停都会触发独特效果，但不会打扰浏览体验。

## 亮点
- **即时反馈**：移动与悬停都有清晰的视觉响应。
- **电影质感**：平滑拖尾、霓虹光感与闪电电弧。
- **开箱即用**：安装后无需设置即可在任意页面生效。

## 模式
- **关闭** — 一键停用所有效果。
- **磁** — 指针位置扩散同心波纹，悬停元素微微放大。
- **光** — 光剑式拖尾，悬停发光并逐步增强。
- **电** — 移动时电弧分段跳跃，悬停时从顶部向目标劈落闪电。

## 行为说明
- **移动时**：每种模式都有专属动效表现。
- **悬停时**：元素产生对应反馈（放大/发光/闪电）。
- **静止时**：效果自动减弱，保持轻量。

## 隐私
Turbo‑Vecter 仅保存所选效果与语言到扩展存储，不收集或上传任何数据。见 [PRIVACY.md](PRIVACY.md)。
