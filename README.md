# Turbo‑Vecter

Turbo‑Vecter is a sci‑fi cursor enhancement that turns every page into a high‑energy UI experience. Pick a mode and watch your pointer leave trails, pulses, and electric arcs without interrupting your browsing.

## Why you'll like it
- **Instant visual feedback**: movement and hover both respond with distinct effects.
- **Cinematic feel**: smooth trails, neon glow, and lightning‑style arcs.
- **Adaptive colors**: switch between dark and light color modes for optimal visibility on any website.
- **Zero friction**: runs on any page, no setup after install.

## Modes
- **Off** — Disable all effects with one tap.
- **Magnetic** — Shrinking circles trail behind your cursor as you move. Hovered elements cycle through animated borders: solid → dotted → flowing → shaking.
- **Light** — A lightsaber‑style trail follows your cursor; hovered elements get a glowing snake ring animation.
- **Electric** — Arc segments crackle on movement; when hovering, a lightning strike charges the element with a bright static glow.

## How it behaves
- **Moving**: each mode renders its own signature motion effect as you move the cursor.
- **Hovering**: elements react with mode‑specific animations (flowing borders, snake rings, or lightning charges).
- **Idle**: effects wind down automatically to stay lightweight.

## Privacy
Turbo‑Vecter stores only your selected effect and language in extension storage. No analytics or tracking. See [PRIVACY.md](PRIVACY.md).
